## Descrição

Como visitante que acessa uma URL inexistente, preciso ver uma página 404 no visual do site (não a padrão do GitHub), para que eu não pense que o site saiu do ar. E como desenvolvedor, quero CSS limpo sem classes idênticas com nomes diferentes.

## Critérios de Aceitação

**SYS-10 — Página 404 customizada:**
- [ ] Arquivo `404.html` criado (GitHub Pages usa este nome automaticamente)
- [ ] Visual consistente com o resto do site — mesmo header, footer e botão WhatsApp
- [ ] Conteúdo: mensagem amigável, link para homepage, botão WhatsApp como alternativa
- [ ] Sem jargão técnico — linguagem acessível para pais de pacientes

**UX-04 — Unificar `.cta-strip` e `.trat-cta-strip`:**
- [ ] Verificar que `.cta-strip` e `.trat-cta-strip` têm exatamente o mesmo CSS
- [ ] Substituir todas as ocorrências de `.trat-cta-strip` por `.cta-strip` nas 12 páginas de tratamento
- [ ] Remover `.trat-cta-strip` do `css/style.css`
- [ ] Verificar zero regressão visual nas páginas de tratamento

## Arquivos a Modificar

- `404.html` — novo arquivo
- `css/style.css` — remover `.trat-cta-strip`
- 12 páginas em `tratamentos/*.html` — substituir classe

## Escopo

**IN:** 404 personalizada, unificação de classes CSS idênticas  
**OUT:** Redesign de páginas de tratamento, nova funcionalidade de busca no 404
