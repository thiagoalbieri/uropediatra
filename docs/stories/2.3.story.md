## Descrição

Como responsável pelo marketing do site, preciso de dados de tráfego para entender quais páginas atraem mais pacientes e como otimizar o conteúdo, além de garantir que a navegação comunique claramente onde o usuário está.

## Critérios de Aceitação

**SYS-12 — Google Analytics:**
- [ ] Conta Google Analytics 4 (GA4) criada para o site
- [ ] Tag de medição (G-XXXXXXX) adicionada ao `<head>` de todas as 18 páginas
- [ ] Evento de conversão configurado para cliques nos botões WhatsApp
- [ ] Dados aparecendo no painel do GA4 (verificar Tempo Real)
- [ ] Alternativa privacidade-first: Plausible Analytics (pago) ou Fathom (pago) — decidir com Dra. Marcela

**UX-01 — Active state na navegação:**
- [ ] Página ativa identificada via JavaScript: comparar `window.location.pathname` com `href` dos links do nav
- [ ] Link ativo recebe classe `.active` e `aria-current="page"`
- [ ] CSS para `.active`: cor `--azul`, font-weight 700, border-bottom ou indicador visual claro
- [ ] Funciona corretamente em homepage, páginas de tratamento (subdiretório) e demais páginas

**UX-14 — Alt text em `sobre.html`:**
- [ ] Todas as imagens em `sobre.html` auditadas
- [ ] Imagens decorativas têm `alt=""`
- [ ] Imagens informativas (foto da Dra. Marcela) têm alt descritivo: `alt="Dra. Marcela Leal da Cruz, uropediatra"`
- [ ] Verificar demais páginas internas se tiverem imagens

## Arquivos a Modificar

- Todas as 18 páginas HTML — tag GA4, active state JS ou link de dados
- `js/main.js` — lógica de active state
- `css/style.css` — estilo de `.active` na navegação
- `sobre.html` — correção de alt text

## Escopo

**IN:** GA4 básico, active state via JS, audit de alt text  
**OUT:** Metas avançadas de GA, heatmaps, A/B testing, Google Search Console (separado)

## Definição de Done

- [ ] GA4 exibe pageviews em Tempo Real
