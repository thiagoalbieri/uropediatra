## Descrição

Como desenvolvedor que mantém o site, preciso que os estilos estejam centralizados no design system CSS e que as classes HTML tenham nomes semânticos corretos, para que qualquer futura edição seja previsível e consistente.

## Critérios de Aceitação

**UX-03 — Extrair inline styles:**
- [ ] Todos os `style="..."` inline inventariados nas páginas do site
- [ ] Cada inline style convertido em classe CSS com nome semântico no `style.css`
- [ ] Locais principais identificados:
  - `contato.html` linhas 42–53 (grid de botões WhatsApp)
  - `telemedicina.html` linha 41 (grid no `sobre-resumo__inner`)
  - `telemedicina.html` linha 63 (`grid-template-columns:1fr`)
  - `index.html` ocorrências múltiplas
- [ ] Nenhum `style="..."` inline remanescente após a refatoração
- [ ] Comportamento visual idêntico antes e depois (zero regressão visual)

**UX-05 — Renomear `.chegou__item` em `telemedicina.html`:**
- [ ] Identificar os elementos em `telemedicina.html` que usam `.chegou__item`
- [ ] Renomear para `.telemed-step` (classe já existente no design system como Molecule)
- [ ] Atualizar CSS: verificar se `.telemed-step` já tem os estilos necessários; se não, migrar estilos do `.chegou__item`
- [ ] Remover definitivamente `.chegou__item` do CSS (após SYS-09 da Story 2.1 já ter removido o observer JS)

## Arquivos a Modificar

- `css/style.css` — novas classes, remoção de `.chegou__item`
- `contato.html`, `telemedicina.html`, `index.html` e demais com inline styles

## Escopo

**IN:** Remoção de inline styles com refatoração para classes, renomeação de classe semântica  
**OUT:** Redesign de componentes, mudança de layout, modularização do CSS monolítico (Story 4.1)

## Notas Técnicas

Para cada inline style encontrado, criar classe seguindo a convenção BEM existente:
- `.contato__whatsapp-grid` para o grid de botões WhatsApp em contato.html
- `.sobre-resumo__inner--telemed` para o override de grid em telemedicina.html
