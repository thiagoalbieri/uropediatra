# Story 1.3 — Open Graph e Preview Social

**Epic:** UROPEDIATRA-DEBT  
**Sprint:** 1  
**Status:** Ready  
**Prioridade:** P1  
**Esforço estimado:** 1 hora  
**Débitos:** SYS-03

---

## Descrição

Como paciente que recebe um link do site via WhatsApp ou redes sociais, preciso ver uma prévia visual com imagem e descrição, para que o site transmita credibilidade antes mesmo de eu clicar.

## Contexto

As tags `og:title` e `og:description` estão presentes na homepage mas `og:image` está ausente. Compartilhamentos no WhatsApp e Facebook aparecem sem imagem — prejudica a percepção de profissionalismo.

## Critérios de Aceitação

**og:image:**
- [ ] Imagem OG criada (1200x630px) ou selecionada das fotos existentes em `img/`
- [ ] Tag `<meta property="og:image" content="URL_ABSOLUTA">` adicionada à homepage
- [ ] URL absoluta (com domínio) — usar URL do GitHub Pages por enquanto
- [ ] Tag `og:image:width` (1200) e `og:image:height` (630) adicionadas
- [ ] Tag `og:image:alt` adicionada com descrição da imagem

**Twitter Card:**
- [ ] `<meta name="twitter:card" content="summary_large_image">` adicionado
- [ ] `<meta name="twitter:image">` com mesma URL da og:image

**Validação:**
- [ ] Preview testado no Facebook Sharing Debugger
- [ ] Preview testado no WhatsApp (enviar link em conversa de teste)

## Arquivos a Modificar

- `index.html` — adicionar meta tags Open Graph completas
- `img/` — adicionar arquivo `og-image.jpg` (1200x630px)

## Escopo

**IN:** og:image, og:image dimensions, og:image:alt, twitter:card para homepage  
**OUT:** OG tags em páginas internas (backlog), redesign da imagem OG

## Sugestão de Imagem OG

Usar `img/marcela.jpg` ou `img/marcela-foto.jpg` (foto profissional da médica) redimensionada para 1200x630px — transmite confiança e humaniza o perfil profissional.

## Definição de Done

- [ ] Facebook Sharing Debugger exibe preview correto
- [ ] WhatsApp exibe preview com imagem ao compartilhar o link
- [ ] Commit realizado e publicado no GitHub Pages
