# Story 2.1 — Quick Wins: Performance e Identidade

**Epic:** UROPEDIATRA-DEBT  
**Sprint:** 2  
**Status:** Ready  
**Prioridade:** P2  
**Esforço estimado:** 3 horas  
**Débitos:** SYS-04 (favicon), SYS-05 (hero fallback), SYS-06 (fonts), SYS-09 (código órfão)

---

## Descrição

Como desenvolvedor responsável pelo site, quero resolver 4 débitos de baixo esforço e alto impacto em uma única sessão de trabalho, para melhorar a performance percebida, identidade visual na aba do browser e qualidade do código.

## Critérios de Aceitação

**SYS-04 — Favicon:**
- [ ] Arquivo `favicon.ico` (32x32px) criado e salvo em `/img/favicon.ico`
- [ ] Tag `<link rel="icon" href="/img/favicon.ico">` adicionada ao `<head>` de todas as 18 páginas
- [ ] Favicon visível na aba do browser em Chrome, Safari e Firefox

**SYS-05 — Hero image fallback:**
- [ ] Imagem hero `img/marcela.jpg` (ou equivalente local) configurada como fallback
- [ ] HTML atualizado: `<img src="img/marcela.jpg" data-src="[URL_UNSPLASH]" loading="lazy">` com JS de lazy-load
- [ ] Alternativa: substituir Unsplash CDN por imagem local diretamente (mais simples)

**SYS-06 — Google Fonts display=swap:**
- [ ] URL do Google Fonts atualizada em todas as 18 páginas para incluir `&display=swap`
- [ ] De: `fonts.googleapis.com/css2?family=Nunito:wght@400;600;700;800;900&family=Inter:wght@400;500;600`
- [ ] Para: `fonts.googleapis.com/css2?family=Nunito:wght@400;600;700;800;900&family=Inter:wght@400;500;600&display=swap`

**SYS-09 — Código órfão:**
- [ ] IntersectionObserver para `.chegou__item` removido de `main.js` (aproximadamente linha 75)
- [ ] Classe CSS `.chegou__item` removida de `css/style.css`
- [ ] Verificar que nenhuma página usa `.chegou__item` antes de remover (exceto telemedicina.html que será tratado em Story 2.4)

## Arquivos a Modificar

- `css/style.css` — remover `.chegou__item`
- `js/main.js` — remover IntersectionObserver órfão
- Todas as 18 páginas HTML — favicon link, Google Fonts display=swap

## Escopo

**IN:** Favicon, fonts swap, hero fallback, remoção de código morto  
**OUT:** Redesign do favicon, mudança de fontes, nova imagem hero

## Definição de Done

- [ ] Favicon visível nos 3 principais browsers
- [ ] Lighthouse Performance melhora (Google Fonts não bloqueia mais)
- [ ] Nenhum código morto de `.chegou__item` no CSS ou JS
- [ ] Commit realizado e publicado no GitHub Pages
