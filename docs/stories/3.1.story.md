# Story 3.1 — Ativação do Domínio Definitivo

**Epic:** UROPEDIATRA-DEBT  
**Sprint:** 3 (executar quando DNS for ativado)  
**Status:** Ready  
**Prioridade:** P1 — Executar quando `www.uropediatra.com.br` for apontado  
**Esforço estimado:** 2 horas  
**Débitos:** SYS-01 (robots/sitemap), SYS-11 (canonical)

---

## Descrição

Como Dra. Marcela, quando o domínio `www.uropediatra.com.br` for ativado, preciso que o site seja indexado corretamente pelo Google com o novo domínio, para que pacientes que busquem meu nome ou especialidade encontrem o site correto.

## Pré-condição

Esta story só pode ser executada após:
- DNS `www.uropediatra.com.br` apontado para GitHub Pages
- CNAME configurado no repositório GitHub Pages
- HTTPS ativo no domínio personalizado

## Critérios de Aceitação

**SYS-01 — robots.txt e sitemap.xml:**
- [ ] `robots.txt`: `Sitemap:` atualizado para `https://www.uropediatra.com.br/sitemap.xml`
- [ ] `sitemap.xml`: todas as 18 + URLs atualizadas de `thiagoalbieri.github.io/uropediatra/` para `https://www.uropediatra.com.br/`
- [ ] `sitemap.xml`: data de `<lastmod>` atualizada para data atual
- [ ] `robots.txt` testado em `https://www.uropediatra.com.br/robots.txt`

**SYS-11 — rel=canonical:**
- [ ] Tag `<link rel="canonical" href="https://www.uropediatra.com.br/{caminho}">` adicionada ao `<head>` de todas as 18 páginas
- [ ] URL canônica única por página — sem trailing slash inconsistente
- [ ] Páginas de tratamento: `https://www.uropediatra.com.br/tratamentos/{slug}.html`

**SEO pós-ativação:**
- [ ] Google Search Console configurado com o novo domínio
- [ ] Sitemap submetido ao Google Search Console
- [ ] Redirect de `thiagoalbieri.github.io/uropediatra` → `www.uropediatra.com.br` configurado (via GitHub Pages custom domain)

## Arquivos a Modificar

- `robots.txt`
- `sitemap.xml`
- Todas as 18 páginas HTML — tag `rel="canonical"`

## Escopo

**IN:** Atualização de URLs em robots.txt, sitemap, canonical  
**OUT:** Redesign de URLs, migração de conteúdo, configuração de servidor

## Definição de Done

- [ ] `https://www.uropediatra.com.br/robots.txt` acessível e correto
- [ ] `https://www.uropediatra.com.br/sitemap.xml` acessível com URLs corretas
- [ ] Canonical correto verificado em 3 páginas diferentes
- [ ] Google Search Console configurado e sitemap submetido
- [ ] Commit realizado
