# Story 1.2 — Formulário de Contato Funcional

**Epic:** UROPEDIATRA-DEBT  
**Sprint:** 1  
**Status:** Ready  
**Prioridade:** P1 — Risco de negócio  
**Esforço estimado:** 4–6 horas  
**Débitos:** SYS-02, UX-02

---

## Descrição

Como paciente ou responsável que prefere não usar WhatsApp, preciso que o formulário de contato do site entregue minha mensagem à Dra. Marcela, para que eu possa ser atendido sem perder tempo esperando por um retorno que nunca vai chegar.

## Contexto

O formulário atual em `contato.html` usa `setTimeout` para simular envio — a mensagem de sucesso é exibida mas nenhum dado é transmitido. Qualquer paciente que use o formulário perde sua oportunidade de contato.

**Solução recomendada:** Formspree (gratuito até 50 envios/mês, sem backend, integra via `action` no `<form>`).

**Alternativa:** EmailJS (gratuito até 200/mês, via JavaScript).

## Critérios de Aceitação

**Integração Formspree:**
- [ ] Conta Formspree criada com e-mail da Dra. Marcela
- [ ] `<form>` em `contato.html` atualizado com `action="https://formspree.io/f/{ID}"` e `method="POST"`
- [ ] Campos obrigatórios: nome, e-mail, telefone, mensagem
- [ ] Submissão real testada — e-mail recebido no destino correto
- [ ] Código JavaScript de placeholder (`setTimeout`) removido de `main.js`

**Feedback ao usuário:**
- [ ] Mensagem de sucesso exibida após envio real (não simulado)
- [ ] Mensagem de erro exibida se envio falhar (sem conexão, etc.)
- [ ] Enquanto P1 for implementado: aviso no topo do formulário informando limitação temporária

**Proteção anti-spam:**
- [ ] Honeypot field configurado (Formspree oferece nativamente)
- [ ] Campo `_replyto` configurado para resposta direta ao paciente

## Arquivos a Modificar

- `contato.html` — atributos do form
- `js/main.js` — remover setTimeout placeholder, adicionar tratamento de resposta real
- `css/style.css` — estilos de estado de erro/sucesso (se necessário)

## Escopo

**IN:** Integração Formspree, remoção do placeholder, feedback de envio  
**OUT:** Backend próprio, autenticação, sistema de CRM, upload de arquivos
