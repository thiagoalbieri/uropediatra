# Story 2.2 — LGPD: Política de Privacidade

**Epic:** UROPEDIATRA-DEBT  
**Sprint:** 2  
**Status:** Ready  
**Prioridade:** P2 — Risco regulatório  
**Esforço estimado:** 3–4 horas  
**Débitos:** SYS-13, UX-12

---

## Descrição

Como Dra. Marcela, preciso que meu site esteja em conformidade com a LGPD (Lei 13.709/2018), informando aos visitantes como seus dados são coletados e tratados, para evitar penalidades da ANPD e transmitir transparência aos pacientes e responsáveis.

## Contexto

O formulário de contato coleta nome, e-mail, telefone e mensagem. Sem política de privacidade publicada, o site está em não-conformidade com a LGPD. A ANPD pode aplicar sanções a partir de notificação. Risco médio mas totalmente evitável.

## Critérios de Aceitação

**SYS-13 — Página de política de privacidade:**
- [ ] Nova página `politica-de-privacidade.html` criada com mesmo header/footer do site
- [ ] Conteúdo cobre:
  - Dados coletados (nome, e-mail, telefone, mensagem via formulário)
  - Finalidade do tratamento (responder consultas, agendar atendimentos)
  - Base legal (consentimento do titular / execução de contrato de saúde)
  - Prazo de retenção dos dados
  - Direitos do titular (acesso, correção, exclusão)
  - Contato do responsável pelo tratamento de dados (Dra. Marcela)
  - Data de vigência da política
- [ ] Linguagem clara e acessível (sem juridiquês excessivo)
- [ ] Página adicionada ao `sitemap.xml`

**UX-12 — Link no footer:**
- [ ] Link "Política de Privacidade" adicionado ao rodapé em todas as 18 páginas
- [ ] Link posicionado após os links de navegação existentes no footer
- [ ] Texto do link: "Política de Privacidade"

## Arquivos a Modificar

- `politica-de-privacidade.html` — novo arquivo
- Todas as 18 páginas HTML — link no footer
- `sitemap.xml` — adicionar nova página

## Escopo

**IN:** Política de privacidade básica LGPD, link no footer, sitemap  
**OUT:** Cookie banner, DPO formal, tratamento de dados sensíveis de saúde (escopo de revisão jurídica separada)

**Nota:** Esta política cobre o formulário de contato. Se no futuro o site implementar prontuário eletrônico ou dados de saúde sensíveis (LGPD art. 11), será necessária revisão jurídica especializada.
